Returning to writing blogs
<2026-08-27T01:07:11:00+03:00> :test:tech:meta:time:

So I had been doing some things with my computer, as I usually do, and I had decided that I would go ahead and switch OSs again. When I ran my tar command, I was selective with which folders I put in, and I forgot to put in ~/.ssh . I lost my ssh keys, and I didn't really touch my programming projects for some time.

I didn't touch my source code projects because I considered that all that I had left was basically complete — as in all that was left to do was not worth doing. I had completed Wawacraft:Evolved v0.3.12, ported it to Windows (with some bugs), created a self documenting command line syntax for the program, had given it a secret OBJ loader, a possibility to load from a different asset folder by a command line argument, had written it an autoconf code and automake code to allow it to get compiled and installed into /usr/local/bin, had created tarballs of the project that self contained everything necessary and installed perfectly, had made edited versions of these archives for windows, implemented terrain generation with a slightly buggy noise generator, implemented block editing features and block switching, slightly better performance on my machine but some strange bugs happening on the windows side of things for some people, etc. etc.

I also had installed slackware, and was more bothered with setting up packages than really looking into my own code. So more hobbyist-sysadmin stuff generally than anything else.

Anyways, I even made this more and more easy for myself that I would write into these files from an org mode capture I implemented in my emacs config file(which I had to rewrite after reinstalling my OS).

So I don't even have to bother with getting into a new file, I just run from a capture, and run the script when I want an export. If I alias the script I could run it from anywhere with a wrapper, but I wouldn't want to do that.
