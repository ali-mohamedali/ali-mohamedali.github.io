Basic introduction to the page sprawl.

Table of Contents

  • 1. Explanation
  • 2. Lack of distinction from the website

You might've noticed when you clicked that link 'Sprawl' on the sidebar that you found yourself in a node called 'rote,' and been introduced to something called the page sprawl??

It's not familiar in most websites to have anything like a page sprawl, except for wikis. It's basic to understand however…

1. Explanation

The page sprawl is an organisation system for my website which uses the metaphor of a filesystem to keep files around:

  • Every directory is an index, and every index is also part of an index which is directly under the root(rote) index.
  • Pages inside the index are organised there based on subject, and can be numerically ordered(this feature was intentionally added to make sure that some indices can actually hold a series of pages meant to be read in order like chapters of a book).

If you've ever browsed a wiki, you will notice that it's like an iceberg. There are not too many landing pages, and it is difficult to get into the heart of the content if you are reading for no reason. However, once you begin reading it like a database and querying for specific subjects you start to find the writings in there. If you are not particularly interested, it is difficult to brainstorm things to ask. Indices solve this by just presenting a menu of things that have been written in proper organisation.

I enjoy wiki organisation, and so I made it so that the page sprawl is like a wiki for me, but at least organised in such a way that readers are able to discover new articles in a way which is not as hard as trying to discover a new chemical element, for example. It has all the regular features of wiki structure — links between pages, images, variety of subjects, categories of pages — but only with a convenient addition of a table of contents.

2. Lack of distinction from the website

The page sprawl is not a distinct part of the website but just another way to browse the same content. There is nothing distinguishing about the idea of a sprawl besides its organisation. In fact, some of these pages are actually symlinks to blogs I have already written but which can be read through this system.

However, the only important distinction is that there is no way to discover changes (yet) to the page sprawl, so it is not to be tracked. The blog is present for tracking, however, and can be added to your feed.
